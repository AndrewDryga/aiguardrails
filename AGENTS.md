# Site contributor instructions

This is a standalone educational publication built with Astro. Keep it deployable
as static files on Cloudflare Pages. The only edge Function retires the former
portfolio URL; keep its invocation routes limited to that URL.
Use `npm run verify` after changes. Inspect affected pages on desktop and mobile.
Do not publish or change DNS unless the user authorizes that action.

Write simple English and answer a real reader question. Read the source before
making a technical claim. Preserve the distinction between measured keyword
demand and useful supporting topics with no data. Research records belong in
`research/`, never the public build. Do not add keywords as filler.

Use Humanizer (https://github.com/blader/humanizer) for prose and Unslop
(https://github.com/heydamir/unslop) for interface review. Keep attribution.
Sources, canonical URLs, sitemap entries and visible bylines must agree.
Examples must state whether they execute or are conceptual. Do not invent tests,
customer stories, ratings, results, legal guarantees or certifications.

Use this publication's own identity in navigation, footers, homepage credits,
bylines, schema, text exports and social images. Do not turn these shared surfaces
into promotion for Emisar, Ryker or co:op, or add a portfolio hub. A useful tool directory may recommend owned products
alongside alternatives, with documented criteria, limits and ownership disclosure. The Emisar
product-site convention of selling in shared page chrome does not apply here.

Emisar, Ryker and co:op share ownership with this publication. Keep that fact in
the editorial policy. Include a product in a guide only when its documented role
helps answer the reader's question, with a brief disclosure near the example.
Do not imply unaffiliated reviews, invent editorial staff, or bundle unrelated
products into a promotional paragraph.

Emisar controls declared remote infrastructure actions via CLI or MCP;
co:op limits a local coding environment; Ryker is an engineering teammate.
None is a blanket security guarantee. Keep teaching useful without a purchase.
